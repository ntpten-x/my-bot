MY-BOT

อ่านโพสต์ส่งเข้า MY-BOT และส่งคอมเมนต์ผ่านหน้าจอ Facebook เฉพาะกฎที่คุณเปิดและผูกกับอุปกรณ์นี้

หลังติดตั้งหรืออัปเดต Extension ถ้ายังไม่เริ่มอ่าน ให้กด Reload ที่ chrome://extensions แล้วเปิด facebook.com ค้างไว้ (หรือรีเฟรชแท็บ Facebook)

จับคู่แล้วเปิด facebook.com ค้างไว้ใน Chrome โปรไฟล์นั้น — ระบบอ่านจากหน้าต่าง Facebook ที่เชื่อมไว้ (ใช้แท็บเฟสที่ว่าง หรือแท็บพื้นหลัง) ไม่เปิดหน้าต่างใหม่ ไม่แย่งแท็บที่คุณกำลังดู

ค่าเริ่มต้นปิด ต้องเปิดกฎและปิด Dry Run บนเว็บด้วย พบ Checkpoint หรือผลไม่ชัดเจนจะหยุด ไม่ส่งซ้ำอัตโนมัติ ปิดสวิตช์นี้เพื่อหยุดรับงานใหม่
