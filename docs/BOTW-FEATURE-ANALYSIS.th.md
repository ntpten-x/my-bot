# วิเคราะห์ BOT-W จากหลักฐานสาธารณะ

วันที่สำรวจ: 6 พฤศจิกายน 2026 — Phase A ยังไม่ครบส่วนหลังเข้าสู่ระบบ

## วิธีสำรวจและข้อจำกัด

ใช้เครื่องมืออ่านเว็บเปิดหน้าและลิงก์สาธารณะเท่านั้น เครื่องมือรายงานเนื้อหาบางหน้าจากดัชนีที่เก็บไว้ก่อนวันสำรวจ จึงไม่ถือเป็นการทดสอบเบราว์เซอร์สด ไม่มีเครื่องมือ Browser Automation สำหรับรับช่วงเบราว์เซอร์ที่เจ้าของล็อกอินเอง ไม่ได้ใช้ข้อมูลเข้าสู่ระบบที่ส่งในแชต ไม่เก็บข้อมูลดังกล่าวในไฟล์ ไม่เรียก API ภายใน ไม่ดาวน์โหลดส่วนขยาย ไม่เปลี่ยนสถานะ ไม่ทดลองส่งข้อความ การเข้าชมอาจปรากฏใน access log ของผู้ให้บริการ

`Verified` หมายถึงตรวจพบหน้า/ข้อความที่อ้างถึงโดยตรง หากเป็นข้อความผู้ให้บริการจะระบุว่าเป็น “ประกาศ” ไม่ใช่ยืนยันผลการทำงาน `Inferred` คือข้ออนุมาน `Unknown` คือไม่มีหลักฐานเพียงพอ

## เมนูและลำดับที่พบ

เมนูสาธารณะมีวิธีการทำงาน หมวดหมู่ แพ็กเกจ ตลาดกลาง สมัคร เข้าสู่ระบบ ลืมรหัสผ่าน แดชบอร์ด FAQ ติดต่อ และเอกสารกฎหมาย ลิงก์วิธีการทำงาน/หมวดหมู่กลับหน้าแรก และ FAQ ไปหน้าแพ็กเกจในผลเครื่องมือครั้งนี้ ไม่ถือว่ามีหน้าแยกหรือได้ทดสอบ accordion/hover/responsive แล้ว

ลำดับที่เว็บไซต์อธิบาย: เลือกงานและตัวกรอง → รับรายการ/แจ้งเตือน → ติดต่อและติดตามสถานะ เป็น Verified ของคำอธิบายหน้าเว็บ ส่วนลำดับเมนูจริงหลังเข้าสู่ระบบยัง Unknown

## Inferred

- กฎและเทมเพลตน่าจะสัมพันธ์กับลีดที่เลือกจากแพ็กเกจ แต่ยังไม่ทราบ schema หรือ workflow จริง (A2–A3)
- ฟีดน่าจะเป็นจุดเริ่มต้นติดตามงาน แต่ตัวอย่างบนหน้าแรกไม่พิสูจน์ latency หรืออัตราเก็บครบ (A1)

## Unknown และสิ่งที่ต้องตรวจต่อ

ยังไม่ทราบชื่อเมนูภายใน การค้นหา/เรียง/แบ่งหน้า เงื่อนไขกฎ การจัดการ error คิว โควตา dedupe และ Start/Pause/Stop จริง ไม่ยืนยันว่ามี Facebook Account Management, OAuth, scopes, token expiry หรือหลายบัญชี และไม่ยืนยันว่า Auto Comment ส่งผ่าน API หรือกลไกใด

Extension มีหลักฐานประกาศ แต่ version, Manifest, permissions, วิธีติดตั้ง และพฤติกรรมจริงยัง Unknown ไม่คัดลอกโค้ดที่ไม่เปิดเผย

หน้าแรกกล่าวถึงเว็บบอร์ด/มาร์เก็ตเพลส แต่ข้อกำหนดระบุเฉพาะ Facebook จึงไม่รับรองแหล่งอื่น ตลาดกลางผู้ให้บริการถูกนำเสนอเป็นแผนอนาคต ไม่จัดเป็นฟีเจอร์ใช้งานจริง

## ขั้นตอนสำหรับเจ้าของ

เจ้าของต้องเปิด [หน้าเข้าสู่ระบบ](https://bot-w.com/login) และล็อกอินเอง หากมีช่องทางเบราว์เซอร์ที่ได้รับอนุญาตในภายหลัง จึงสำรวจต่อเฉพาะหน้าบัญชีที่เข้าถึงได้ ระหว่างนี้รับชื่อเมนู/คำอธิบายขั้นตอนเป็นข้อความที่เจ้าของตรวจและตัดข้อมูลส่วนตัวแล้วได้ ไม่ส่งรหัสผ่าน Cookie หรือ Session Token หากต้องกดคำสั่งที่อาจเปลี่ยนข้อมูล ให้หยุดและรายงานก่อน
