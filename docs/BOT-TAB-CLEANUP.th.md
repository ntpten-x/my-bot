# ปิดแท็บที่บอทเลิกใช้ — ส่วนขยาย 1.11.15

ทำงานอัตโนมัติหลัง Reload ส่วนขยาย ไม่ต้องเปิดสวิตช์เพิ่ม และไม่เริ่มส่งคอมเมนต์แทนเจ้าของ

รุ่น 1.11.15 แก้แท็บอ่านเนื้อหาเต็มที่ยังจำ URL เป็น `about:blank` หลังบอทนำทางไปหน้าโพสต์ และแยกกรณี Chrome อ่านข้อมูลแท็บไม่ได้ออกจากแท็บที่ไม่มีแล้ว จึงไม่ลืม ownership โดยไม่ได้ปิด เพิ่มการลองใหม่แบบเว้น 30/60/120 วินาทีและ 5 นาที พร้อมรักษาข้อมูลค้าง

ป๊อปอัปแสดงเหตุผลว่า **กำลังอ่าน / คอมเมนต์ / รออ่านต่อ / รอปิด / รอเก็บกวาด / คืนให้เจ้าของแล้ว** และมีปุ่ม **ปิดแท็บบอทที่เลิกใช้** ซึ่งไม่ปิดงานที่กำลังทำ แท็บส่วนตัว หรือ cursor ที่ยังจำเป็น หน้าภาพรวมมีสถานะเดียวกันจากอุปกรณ์ที่รายงานล่าสุด หากข้อมูลเก่า/ส่วนขยายคนละรุ่นจะไม่สรุปว่าคิวเป็นศูนย์

| แท็บ | เมื่อใดที่ปิด |
| --- | --- |
| อ่านโพสต์/อ่านเนื้อหาเต็ม | เมื่องานเสร็จหรือเลิกใช้แท็บนั้น |
| แท็บว่างในหน้าต่างเก็บโพสต์ | เมื่อไม่มี reader ในหน้าต่างนั้นเหลืออยู่ |
| ส่งคอมเมนต์อัตโนมัติ | หลังจบขั้นตอน หรือขั้นตอนล้มเหลว |
| แท็บค้างจาก MV3 รีสตาร์ต | เมื่อรอบกู้คืนพบหลักฐาน ownership ใน session |
| reader ที่พักรออ่านต่อ | เก็บไว้ขณะยังจำเป็น สูงสุดตามอายุ continuation เดิม 2 ชั่วโมง; เมื่อพักการเก็บหรือพักบัญชี จะคืนแท็บที่ไม่ active ใน heartbeat ถัดไป |

หากฟีดไม่คืบหน้าติดต่อกัน 3 รอบย่อยที่ได้ผล loading/stalled/limit จะคืนแท็บและเก็บ durable recovery ไว้ให้รอบถัดไปกู้ใหม่ ไม่นับการพักเพราะ quiet/account/outbox และไม่นับการอ่านผ่านโพสต์ที่รู้จักแล้วแต่ตำแหน่งยังเดินหน้าว่าไม่คืบหน้า ไม่ต้องปิดทุกแท็บเมื่อหมดรอบย่อย

หาก Chrome ปฏิเสธการปิดชั่วคราว จะเก็บข้อมูล ownership ไว้ให้รอบถัดไปลองปิดใหม่ ไม่เปิดงานหรือส่งคอมเมนต์เดิมซ้ำเพื่อแก้แท็บค้าง เวลา alarm อาจช้ากว่ากำหนดได้เมื่อ Chrome พักการทำงาน

แท็บที่เจ้าของเปิดเองและแท็บช่วยตอบลีดด้วยมือยังคงอยู่ หากเจ้าของเปลี่ยนแท็บบอทไปหน้าอื่น จะปล่อยแท็บนั้นให้เจ้าของใช้งานต่อ ไม่ปิดหน้าต่างทั้งใบเมื่อมีแท็บส่วนตัวอยู่ภายใน

## เหตุที่รุ่นก่อนยังมีแท็บเหลือ

`closeReader()` ปิดเฉพาะ reader แต่คงแท็บ `about:blank` ที่ใช้สร้างหน้าต่าง และลบ metadata แม้ Chrome ปิดแท็บไม่สำเร็จ ส่วนคอมเมนต์ปิดใน `finally` อยู่แล้ว แต่ MV3 ถูกหยุดก่อนเข้า `finally` ได้ และไม่มี tab ownership แยกจาก journal ซึ่งอาจถูกลบหลังรายงานสำเร็จก่อนปิดแท็บ

แก้โดยเก็บกวาดแท็บว่างเฉพาะ ID ที่บอทสร้าง เก็บ `closing` เมื่อปิด reader ไม่สำเร็จ และเพิ่ม `commentTab` ใน `chrome.storage.session` สำหรับกู้แท็บคอมเมนต์ มีการตรวจ URL ก่อนคืนแท็บที่เจ้าของเปลี่ยนไปใช้งานอื่น การตรวจคอมเมนต์หลัง restart ใช้เฉพาะแท็บที่มี ownership ไม่ค้นหาแท็บส่วนตัวจาก URL ที่ตรงกัน และจำกัดการตรวจ DOM ไว้ 5 วินาที

## ขอบเขตของการกู้คืน

- รักษา continuation ที่ยังต้องอ่านต่อและไม่แตะ active reader
- การคืน reader ที่พักไว้ไม่ลบ outbox, pending posts หรือ durable coverage recovery
- หากรายงานคอมเมนต์ส่งไม่สำเร็จ จะเก็บ journal/pending report ไว้ แม้คืนแท็บไปแล้ว สถานะที่คลุมเครือยังไม่ส่งซ้ำอัตโนมัติ
- `storage.session` อยู่ข้ามการพัก/รีสตาร์ต MV3 ตามปกติ แต่ไม่ได้เป็นหลักฐาน ownership หลังปิด Chrome ทั้งโปรแกรมหรือ Reload/อัปเดตส่วนขยาย จึงไม่เดาว่าแท็บเก่าที่ไม่มี metadata เป็นของบอทแล้วปิดตาม URL

## การตรวจสอบ

ชุดทดสอบใช้ Chrome API จำลอง ไม่มีการส่ง Facebook comments จริง:

```powershell
npm.cmd test -- tests/extension/reader-focus.test.ts tests/extension/comment-worker.test.ts tests/extension/continuous-reader.test.ts
```

ครอบคลุมงานเสร็จ, หน้าต่างมีแท็บส่วนตัว, reader อีกตัวที่ยังทำงาน, continuation, บัญชีพัก, ปิดไม่สำเร็จแล้วลองใหม่, journal หลัง restart, รายงาน offline, DOM recovery ค้าง และการไม่ส่งซ้ำ

ผลตรวจรวมกับ PostgreSQL ทดสอบแยก: **747 tests ผ่าน**, ข้าม 4 ข้อเฉพาะ Linux/VNC บน Windows และ `npm run build` ผ่านแล้ว ยังไม่ deploy ต้องอัปเดตเว็บและส่วนขยายให้ตรงรุ่นก่อนใช้งาน

ตัวเลขข้างบนเป็นผลรุ่น 1.11.11 รายละเอียดสาเหตุและการแก้รุ่นปัจจุบันอยู่ใน [แบบและผลหลังแก้ lifecycle](BOT-TAB-LIFECYCLE-DESIGN.th.md) มี regression เชื่อม full-text เปิด/อ่าน/ปิดจริง, lookup ชั่วคราว, retry spacing, แท็บถูกย้ายหน้าต่าง, blank containers หลายหน้าต่าง, no-progress recovery, popup sender และ heartbeat

ผลรุ่น **1.11.15**: PostgreSQL ทดสอบแยกผ่าน **824/824 ข้อ**, production build ผ่าน ยังไม่ deploy หรือส่งคอมเมนต์จริง

แท็บเก่าที่หลุดข้อมูลติดตามหลังบั๊กหรือ Reload ครั้งก่อนอาจต้องปิดเองครั้งแรก รุ่นนี้จะไม่ปิดแท็บ Facebook ทุกใบตาม URL

## รุ่น 1.11.17

แท็บอ่านที่จบงานยังปิดทันที รุ่นนี้เพิ่มการคืนแท็บพักที่ไม่ได้กลับมาอ่านเกิน 5 นาที และปุ่มเก็บกวาดคืนแท็บพักได้ทันที โดยเก็บ recovery/pending posts ไว้และข้ามแท็บที่กำลังทำงานเสมอ รายละเอียดและข้อจำกัดอยู่ใน [บันทึกแก้ความเสถียร 1.11.17](RELIABILITY-1.11.17.th.md)
