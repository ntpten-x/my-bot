# จัดการบัญชี Facebook

เมนู **จัดการบัญชี** (`/accounts`) แสดงบัญชี Facebook ที่ส่วนขยายเคยรายงานเข้าระบบ ไม่ได้ดึงรายชื่อบัญชีอื่นจาก Facebook และไม่ขอรหัสผ่านหรือคุกกี้ Facebook

## เชื่อมบัญชี

1. จับคู่ส่วนขยายกับแอปที่ **ตั้งค่า → ส่วนขยาย Chrome**
2. ล็อกอิน Facebook บนโปรไฟล์ Chrome นั้น ส่วนขยายรายงานรหัสบัญชี (`c_user`) และชื่อที่อ่านได้
3. เปิด `/accounts` บัญชีปรากฏหลัง heartbeat รอบแรก (ปกติทุก 1 นาที)
4. ถ้าส่วนขยายอ่านชื่อไม่ได้ จะแสดงรหัส Facebook แทน

ส่วนขยายเวอร์ชัน **1.11.7** รองรับการหยุดบัญชีจากระบบและคิวคอมเมนต์ที่ปรับปรุงแล้ว หลังอัปเดตโค้ดให้ไป `chrome://extensions` แล้วกด Reload ส่วนขยาย MY-BOT ทุกโปรไฟล์ที่ใช้

## สถานะ

- **ออนไลน์ / เชื่อมต่ออยู่**: มีอย่างน้อยหนึ่งส่วนขยายรายงานว่าบัญชีนี้ล็อกอินอยู่และส่ง heartbeat ภายใน 3 นาทีล่าสุด ไม่ใช่สถานะ Active ของ Facebook
- **ออฟไลน์**: ไม่พบ heartbeat ที่เข้าเงื่อนไข ไม่สรุปว่าบัญชีถูกแบนหรือรหัสผ่านผิด
- **พร้อมรับงาน**: อนุญาตจากหน้าจัดการบัญชี มีการเชื่อมต่อที่เปิดงานในส่วนขยายและใช้เวอร์ชันที่ระบบรองรับ ไม่ได้แปลว่ากำลังอ่านหรือส่งคอมเมนต์อยู่
- **หยุดงานจากระบบ**: เจ้าของหยุดบัญชีนี้ แม้เชื่อมต่ออยู่ก็ไม่รับงานใหม่
- **พักงานที่ส่วนขยาย**: บัญชีเชื่อมต่อแต่ส่วนขยายพักงานไว้ ต้องเปิดจากส่วนขยายด้วย
- **ต้องอัปเดตส่วนขยาย**: ยังไม่มีการเชื่อมต่อที่เปิดงานและใช้เวอร์ชันที่ระบบรองรับ

บัญชีเดียวในหลายโปรไฟล์แสดงเป็นหนึ่งบัญชี พร้อมรายการการเชื่อมต่อแต่ละส่วนขยาย ออนไลน์ถ้ายังมีอย่างน้อยหนึ่งการเชื่อมต่อที่ตรงเงื่อนไข หน้านี้อัปเดตทุก 15 วินาที

## เปิดและหยุดงาน

**หยุดทำงาน** บันทึกสถานะถาวรแยกจากสถานะล็อกอิน มีผลทุกอุปกรณ์ที่ใช้บัญชีนี้กับเซิร์ฟเวอร์ที่อัปเดตแล้ว เซิร์ฟเวอร์ไม่แจกกลุ่ม/งานอ่านใหม่ ไม่รับโพสต์/ตัวอย่างโพสต์ และไม่อนุญาต claim/authorize คอมเมนต์ใหม่ ยังคงรับ heartbeat และรายงานผลของงานเดิม เพื่อไม่ทำให้ประวัติการส่งคลุมเครือ

ส่วนขยายเก็บคิวโพสต์เดิมเมื่อเซิร์ฟเวอร์ตอบ `423 ACCOUNT_PAUSED` ไม่ลบทิ้งหรือทำเครื่องหมายเป็นข้อมูลเสีย รอเปิดงานอีกครั้งแล้วจึงส่งต่อ โดยยังใช้กติกาอายุคิว 72 ชั่วโมงและใบรับข้อมูลเดิม

ส่วนขยายรับสถานะหยุด/เปิดทาง heartbeat รอบถัดไป (ประมาณ 1 นาที) รอบอ่านที่เริ่มไปแล้วอาจทำต่อได้ช่วงหนึ่ง สิทธิ์กดส่งคอมเมนต์ที่ออกไปแล้วอาจทำงานต่อได้ถึง 3 วินาที ห้ามถือว่าหยุดพร้อมกันทุกอุปกรณ์ทันที

**เปิดทำงาน** เพียงอนุญาตให้รับงาน ไม่ล็อกอิน Facebook ไม่เปิดปุ่มพักในส่วนขยาย และไม่เปิด Auto Comment หรือยินยอมส่งแทนเจ้าของ การส่งจริงต้องผ่านสิทธิ์และการตั้งค่าเดิมทั้งหมด

## ข้อมูลและข้อจำกัด

ใช้ `FbAccount` และ `ExtensionHeartbeat` เดิม ค่าหยุดเก็บใน `Setting` ชื่อ `facebook_account_paused_<id>` เป็นสถานะของบัญชีทั่วระบบ ไม่ใช่สถานะเฉพาะเครื่อง สำรองผ่านระบบเดิม ไม่เพิ่มตารางหรือ migration

heartbeat ไม่เขียนทับค่าหยุด การควบคุมฝั่งเซิร์ฟเวอร์ตรวจรหัสในคำขอและบัญชีล่าสุดของอุปกรณ์ที่จับคู่ ไม่เก็บหรือส่งคุกกี้ Facebook หากมีบัญชีที่ถูกหยุด แต่คำขอเก่าระบุบัญชีไม่ได้ ระบบไม่แจกงานให้จนกว่าจะรายงานตัวตนได้ เพื่อป้องกันการข้ามสถานะหยุด ให้ Reload ส่วนขยายและตรวจการจับคู่

สถานะเป็นข้อมูลที่ส่วนขยายรายงาน ไม่ใช่การยืนยันจาก Facebook API เครื่องหรือเซิร์ฟเวอร์อื่นที่ยังรันโค้ดเก่าต้องอัปเดตก่อนจึงจะบังคับการหยุดบัญชีได้
