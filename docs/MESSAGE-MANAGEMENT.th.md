# จัดการข้อความ

เปิด **จัดการข้อความ** (`/messages`) เพื่อสร้างข้อความสำหรับใช้คอมเมนต์:

1. เลือก **หมวดหมู่** เช่น เกม
2. เลือก **ประเภท** เช่น Roblox หรือเลือก **ทุกประเภทในหมวดหมู่** เพื่อใช้ร่วมกันทั้งหมวดหมู่
3. ตั้งชื่อ เช่น “แนะนำร้าน” หรือ “แจ้งโปรโมชัน”
4. ใส่เนื้อหา แล้วแนบรูปได้หนึ่งรูปถ้าต้องการ (JPEG / PNG / WebP ≤ 2.5 MB)
5. กด **สร้างข้อความ**

ประเภทหนึ่งสร้างได้หลายชุด เมื่อบันทึกแล้วหมวดหมู่และประเภทเดิมยังถูกเลือกไว้ให้เพิ่มชุดถัดไป เก็บรวมทั้งระบบได้สูงสุด 300 ชุด ชื่อไม่เกิน 60 ตัวอักษรและเนื้อหาไม่เกิน 2,000 ตัวอักษร รูปไม่บังคับ — ข้อความอย่างเดียวยังใช้ได้ตามเดิม

กรองตามหมวดหมู่/ประเภทและค้นหาชื่อหรือเนื้อหาได้ **แก้ไข** ใช้เปลี่ยนชื่อ เนื้อหา รูป หรือย้ายหมวดหมู่/ประเภท **คัดลอก** ใช้นำข้อความไปวาง และ **ลบ** ต้องยืนยันก่อนลบ (ลบรูปใน Storage ด้วย)

รูปเก็บใน Supabase Storage บัคเก็ต `message-images` (private) ผ่าน `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` path แบบ `templates/{id}/{uuid}.ext` เมื่อกฎคอมเมนต์เลือกข้อความที่มีรูป ระบบคัดลอก `imagePath` ลง snapshot ของกฎ/งาน แล้ว Extension (≥ 1.11.28) ดึง signed URL ไปแนบไฟล์ก่อนส่ง — ถ้าแนบรูปไม่ได้จะไม่กดส่งข้อความเปล่าแทน

ข้อความอ้างหมวดหมู่ (`ReplyTemplate.categoryId`) และประเภท (`ReplyTemplate.productId`) ไม่เก็บรายชื่อกลุ่มแบบตายตัว จึงไม่ต้องสร้างข้อความซ้ำเมื่อเพิ่มกลุ่มในประเภทเดิม หมวดหมู่หรือประเภทที่มีข้อความจะลบไม่ได้ ต้องย้ายหรือลบข้อความก่อน

ข้อความเดิมที่เลือกเพียงหมวดหมู่จะแสดงว่า **ทุกประเภท** และยังคงเดิม ข้อความทั่วไป หมวดย่อย หรือข้อความเจาะจงรายกลุ่มจัดการได้ที่ **ข้อความสำเร็จรูป** (`/templates`) ทั้งสองหน้าใช้คลังเดียวกันและระบบสำรองเดิม

การบันทึกไม่ส่งคอมเมนต์ ไม่เปิดระบบอัตโนมัติ และไม่เปลี่ยนกฎส่งเดิม เส้นทางร่าง/เลือกข้อความเดิมยังพิจารณาหมวดโพสต์ ประเภทสินค้า และเงื่อนไขของข้อความด้วย หากต้องการส่งต้องตั้งค่าและยินยอมตามระบบเดิม
