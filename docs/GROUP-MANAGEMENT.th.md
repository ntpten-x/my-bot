# จัดการกลุ่ม Facebook

เปิดเมนู **จัดการกลุ่ม** (`/groups`) โครงสร้างคือ **หมวดหมู่ → ประเภท → กลุ่ม Facebook**

ตัวอย่าง:

| หมวดหมู่ | ประเภท |
| --- | --- |
| เกม | Roblox, ROV, PUBG |
| ไอที | คอม, มือถือ, ไอแพด |
| อาหาร | ของสด, อาหารสำเร็จรูป |

## เริ่มใช้งาน

1. ใช้ **สร้างหมวดหมู่** เช่น เกม หรือไอที
2. ในส่วน **สร้างประเภทภายใต้หมวดหมู่** เลือกหมวดหมู่ ตั้งชื่อประเภท แล้วกด **สร้างประเภท**
3. ในส่วน **เพิ่มกลุ่ม Facebook** เลือกหมวดหมู่และประเภท วางลิงก์กลุ่มเดียวหรือหลายกลุ่ม บรรทัดละหนึ่งลิงก์ แล้วกด **เพิ่มกลุ่ม**
4. ชื่อกลุ่มไม่จำเป็น ใช้เฉพาะเมื่อเพิ่มทีละกลุ่ม ถ้าเว้นไว้ระบบตั้งชื่อจากรหัสในลิงก์ให้ก่อน
5. คลิกหมวดหมู่หรือประเภทในแถบด้านซ้ายเพื่อกรองกลุ่ม หรือค้นหาชื่อ/ลิงก์ได้

ลิงก์มือถือและลิงก์โพสต์ในกลุ่มถูกแปลงเป็นลิงก์กลุ่มมาตรฐาน ลิงก์ซ้ำหรือผิดจะแสดงจำนวนเพิ่มไม่ได้และคงอยู่ในช่องให้แก้ไข

## แก้ไขข้อมูล

แต่ละกลุ่มเลือกหมวดหมู่และประเภทใหม่ได้ กด **บันทึกหมวดหมู่และประเภท** เพื่อบันทึกทั้งสองค่าพร้อมกัน เมื่อเปลี่ยนหมวดหมู่ ช่องประเภทจะล้างค่าเดิมและแสดงเฉพาะประเภทของหมวดหมู่ใหม่

กด **จัดการ** ข้างหัวข้อ **หมวดหมู่** เพื่อแก้ชื่อหรือลบหมวดหมู่และประเภท การแก้ชื่อไม่เปลี่ยนรหัสอ้างอิงของกลุ่มและข้อความ

- ลบหมวดหมู่ได้เมื่อไม่มีประเภท หมวดย่อย หรือชุดข้อความ กลุ่มจะกลับไปเป็นยังไม่จัดหมวดหมู่ ส่วนหมวดโพสต์ที่อ้างหมวดหมู่นั้นจะถูกยกเลิก
- ลบประเภทได้เมื่อไม่มีชุดข้อความ กลุ่มยังอยู่ในหมวดหมู่เดิมแต่กลับไปเป็นยังไม่เลือกประเภท ป้ายประเภทของโพสต์ที่อ้างประเภทนั้นจะถูกยกเลิก
- การลบทั้งสองแบบมีข้อความยืนยัน ไม่ลบกลุ่มหรือโพสต์
- ใช้ **พักอ่าน** เพื่อพักเก็บโพสต์จากกลุ่มชั่วคราว รอบอ่านและสถานะละเอียดอยู่ที่ **แหล่งข้อมูล**

## ข้อมูลเดิมและการเชื่อมต่อ

หมวดหมู่ใช้หมวดหลักเดิม (`Category`) ประเภทใช้ข้อมูลเกม/สินค้าเดิม (`Product.categorySlug`) ที่ระบบมีอยู่แล้ว กลุ่มเก็บหมวดหมู่ใน `Source.boundCategorySlug` และประเภทใน `Source.defaultProductId` ไม่ต้องเพิ่มตารางหรือย้ายข้อมูล ข้อมูลสำรองใช้ระบบเดิม

กลุ่มเก่าที่เลือกเพียงหมวดหมู่จะยังอยู่และแสดง **ยังไม่เลือกประเภท** เลือกประเภทเพิ่มเติมได้ กลุ่มที่เคยตั้งเกม/สินค้าหลักไว้ถูกต้องจะแสดงประเภทนั้นทันที การจัดหมวดหมู่และประเภทไม่เขียนหมวดของโพสต์เก่าย้อนหลัง แต่เป็นข้อมูลผูกกลุ่มสำหรับระบบคัดแยกเดิม

**จัดการข้อความ** (`/messages`) เลือกหมวดหมู่และประเภทเดียวกันได้ แต่ละประเภทมีหลายชุดข้อความ หรือเลือกทุกประเภทในหมวดหมู่เพื่อใช้ข้อความร่วมกัน ข้อความเดิมที่เลือกเพียงหมวดหมู่ยังคงเดิม

กลุ่มใหม่เปิดอ่านตามรอบปกติ ต้องเชื่อมส่วนขยายและล็อกอิน Facebook ด้วยบัญชีที่เข้าถึงกลุ่มได้ การเพิ่มกลุ่มหรือข้อความไม่เปิดส่งคอมเมนต์
