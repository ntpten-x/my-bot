# รีดีไซน์หน้า Login — Radar Quiet Gate

เจ้าของอนุมัติ: เลย์เอาต์กลางจอชิ้นเดียว (A) · MFA แสดงตลอด (A) · สไตล์ Radar Quiet Gate (แนวทาง 1)

## เป้าหมาย

ให้หน้า `/login` สวย เรียบ ใช้งานง่าย ทันสมัย สอดคล้องธีม dark/light ของ MY-BOT โดยแบรนด์ MY-BOT เป็นจุดเด่นของ viewport แรก และคงพฤติกรรม auth เดิมครบ

## สถานะเดิม

ฟอร์มกลางจอใน `src/app/login/page.tsx` มี username / password / MFA / ลืมรหัส ใช้ `Card` + โทเคนธีมแล้ว แต่หัวข้อรองยาว และแบรนด์ยังเป็น eyebrow เล็กๆ ไม่ใช่ฮีโร่

## เลย์เอาต์

องค์ประกอบ viewport แรกเท่านั้น:

1. **ThemeToggle** มุมบนขวา (ล็อกอินได้ทั้งสองโหมดก่อนเข้าแอป)
2. **แบรนด์** กลางแนวตั้ง: `MY-BOT` ขนาดใหญ่ + ประโยครองหนึ่งบรรทัด
3. **การ์ดฟอร์ม** ใต้แบรนด์: ช่องกรอก + error + ปุ่มเต็มกว้าง + ลิงก์ลืมรหัส
4. สถานะโหลด (`/api/auth/status`): ข้อความสั้นในพื้นที่การ์ด ไม่แทนที่ทั้งหน้าด้วยสปินเนอร์รก

ความกว้างฟอร์มสูงสุดประมาณ `28rem` · จัดกลางจอ · padding ข้างมือถือเพียงพอ

ไม่ใช้สปลิตสองคอลัมน์ · ไม่ใช้พื้นหลังภาพฮีโร่ · ไม่ใช้ gradient ม่วง/glow การ์ดซ้อน

## สไตล์ (ใช้โทเคนที่มีอยู่)

| องค์ประกอบ | โทเคน / แนว |
| --- | --- |
| พื้นหน้า | `bg` |
| หัว MY-BOT | `fg` · semibold · ขนาด display |
| ประโยครอง | `muted` · หนึ่งบรรทัด |
| การ์ด | `card` + `border-line` · มุมมนตาม UI เดิม · ไม่เงาหนา |
| ป้ายฟิลด์ | `fg` / medium |
| คำใบ้ | `muted` · เล็ก |
| โฟกัส | ring `accent` |
| ปุ่มหลัก | `bg-accent` + `text-on-accent` · เต็มความกว้าง |
| ลิงก์ | `accent` |
| error | `danger` + `role="alert"` |

ไม่ใส่ข้อความ ALL-CAPS แบบ “LEAD RADAR”

## ฟอร์มและพฤติกรรม

ฟิลด์ (ลำดับ):

1. ชื่อผู้ใช้ — คง validation / autocomplete / ค่าเริ่มต้น `admin` ตามของเดิม
2. รหัสผ่าน
3. รหัส Authenticator (ถ้ามี) — แสดงตลอด; เว้นว่างได้ถ้ายังไม่เปิด MFA
4. ปุ่มเข้าสู่ระบบ (disabled ตอน busy)
5. ลิงก์ `/reset-password`

คง logic เดิม:

- `GET /api/auth/status` → authenticated → `/dashboard`; needsSetup → `/setup`
- `POST /api/auth/login` ด้วย `{ username, password, code }`
- weak password หรือ mfaSetupRequired → `/settings/security` มิฉะนั้น `/dashboard`
- แสดง error จาก `ApiError`

## ไฟล์ที่คาดว่าจะแตะ

- `src/app/login/page.tsx` — โครงและสไตล์หลัก
- อาจใช้ `ThemeToggle` จาก `@/components/layout/theme-toggle` (หรือ shim เดิม)
- ไม่บังคับย้ายไป `features/` ในรอบนี้

## นอกขอบเขต

- เปลี่ยน API, session, MFA, CSP, หรือกฎรหัสผ่าน
- รีดีไซน์ `/setup` และ `/reset-password` (ทำทีหลังให้เข้าโทนได้)
- OAuth / ล็อกอินโซเชียล
- เปลี่ยนโทเคนธีมกลางทั้งแอป

## ตรวจรับ

- Viewport แรกอ่านเป็น MY-BOT + ประโยครอง + ฟอร์มเดียว
- ThemeToggle ทำงานบนหน้า login
- ล็อกอินสำเร็จ / ผิดพลาด / ลืมรหัส / redirect setup&auth ทำงานเหมือนก่อน
- Dark และ light อ่านง่าย
- มือถือไม่ล้นแนวนอน
- เมื่อลงมือ: `npm test` และ `npm run build` ผ่าน
