# UX/UI Sidebar และเมนูนำทาง

เจ้าของอนุมัติ: เมนูจัดกลุ่มพับได้ (A) · มือถือเป็น drawer โครงเดียวกับเดสก์ท็อป (A) · สไตล์ Radar Console แถบ active บาง + พื้น accent-soft (แนวทาง 1)

งานนี้ต่อจาก `docs/superpowers/specs/2026-11-20-app-structure-design.md` — ชิ้นเลย์เอาต์อยู่ใน `components/layout/`

## เป้าหมาย

ให้เจ้าของคนเดียวหาหน้าได้เร็ว เมนูดูเรียบ สบายตา ทันสมัย ใช้โทนธีม dark/light ที่มีอยู่ โดยไม่ตัดหน้าและไม่เปลี่ยน URL

## ปัญหาของเดิม

- รายการแบน ~19 ข้อใน sidebar และชิปเลื่อนบนมือถือ
- หัวข้อ “LEAD RADAR” แบบติดตามตัวอักษรทำให้ดูแน่นโดยไม่ช่วยนำทาง
- ไม่มีลำดับชั้นข้อมูล — ฟีดกับตั้งค่าอยู่ระดับเดียวกันทั้งก้อน

## แนวทาง: Radar Console

- พื้น sidebar เข้มทั้งสองโหมด (โทเคน `sidebar`)
- หัวกลุ่มตัวเล็กสี muted + เชฟรอนพับ/ขยาย — ไม่ใช้ ALL-CAPS
- รายการ: ไอคอน 16px + ป้ายภาษาไทย
- Active: แถบ accent กว้าง 2px ด้านซ้าย + `bg-accent-soft` + ข้อความชัด
- Hover: `bg-white/5` (บน sidebar)
- ไม่มีการ์ดซ้อน / เงาหลายชั้น / gradient ตกแต่ง
- Motion สั้นเมื่อเปิดกลุ่มหรือ drawer — เคารพ `prefers-reduced-motion`

## เดสก์ท็อป

- ความกว้างประมาณ 260px ในกริด AppShell
- หัว sidebar: **MY-BOT** (hero ของแบรนด์ใน chrome) + คำอธิบายหนึ่งบรรทัดสั้นๆ; ไม่ใส่ eyebrow “LEAD RADAR”
- `nav` เลื่อนในแนวตั้งได้ถ้าสูงเกินจอ; ท้ายแถบติด ThemeToggle + ออกจากระบบ คั่นด้วยเส้น `border-white/10`
- Badge unread ที่รายการ `/notifications` เมื่อมีค่ายังไม่อ่าน
- Active match: pathname ตรง หรือเป็น prefix ของหน้า settings ลูก (`/settings/...` นับว่าอยู่ใต้ตั้งค่า)

## มือถือ

- `Header` บาง: ปุ่มเปิดเมนู · MY-BOT · ThemeToggle (ออกจากระบบอยู่ใน drawer ท้ายแถบ)
- Drawer สไลด์จากซ้าย เต็มความสูง · โครงกลุ่ม/รายการเหมือนเดสก์ท็อป
- ปิดเมื่อ: เลือกลิงก์ · คลิกพื้นหลัง · Escape · ปุ่มปิด
- หลังปิด ให้โฟกัสกลับปุ่มเปิดเมนู
- เลิกใช้แถบชิปเลื่อนแนวนอนของเมนูทั้งหมด

## สถานะพับกลุ่ม

- เก็บใน `localStorage` คีย์ `mybot.nav.groups` เป็นแมป `{ [groupId]: boolean }` (true = ขยาย)
- ค่าเริ่มต้นถ้าไม่มีใน storage: ขยายกลุ่ม `start` และ `leads`; ที่เหลือพับ
- ถ้า pathname อยู่ในกลุ่มใด กลุ่มนั้นขยายเสมอ (ทับค่าที่พับไว้ระหว่างอยู่หน้านั้น)
- การพับ/ขยายด้วยมืออัปเดต storage ทันที

## ชิ้นคอมโพเนนต์ (เป้าหมาย)

| ชิ้น | หน้าที่ |
| --- | --- |
| `nav-config.ts` | นิยามกลุ่มและรายการเมนูที่เดียว |
| `Sidebar` | เดสก์ท็อป: หัว + nav กลุ่ม + ท้ายแถบ |
| `NavGroups` | UI พับกลุ่ม + รายการลิงก์ (ใช้ร่วม drawer) |
| `Header` | มือถือ: ปุ่มเมนู + แบรนด์ + ธีม |
| `MobileNav` / Drawer | แผงมือถือ + backdrop + ปิด |
| `AppShell` | ประกอบ Sidebar + Header + Main + Footer |

## นอกขอบเขต

- Icon rail พับแคบ / mega menu
- ตัดหรือรวมหน้า route
- เปลี่ยนธีมสีกลางหรือฟอนต์ทั้งแอป
- แตะ extension, API, worker

## ตรวจรับ

- เดสก์ท็อป: จัดกลุ่มพับได้ · จากกลุ่มไปฟีด/คอมเมนต์/ตั้งค่าได้ภายในสองคลิกตามลำดับชั้น
- กลุ่มที่มีหน้าปัจจุบันขยายอัตโนมัติ
- มือถือ: drawer ใช้ได้ · ไม่มีชิปเมนูเลื่อนยาว
- ThemeToggle, unread badge, logout ทำงาน
- จำสถานะพับกลุ่มหลังรีเฟรช (ยกเว้นกลุ่มของหน้าปัจจุบันที่ต้องเปิด)
- เมื่อลงมือ: `npm test` และ `npm run build` ผ่าน
