# ตั้งกฎคอมเมนต์ตามเจตนา

## สิ่งที่เพิ่มในรอบนี้

หน้า `/auto-comment` เลือกได้สามแบบ: คนหาซื้อ/ขอคำแนะนำ, คนเสนอขาย และคำสำคัญอย่างเดียว กฎเดิมคงเป็นคำสำคัญอย่างเดียว ไม่เปิดกฎหรือเพิ่มสิทธิ์ส่งให้เอง กฎใหม่จากฟอร์มเริ่มเป็นคนหาซื้อและยังปิดอยู่

ใช้ตัวตรวจเจตนาภาษาไทยร่วมกับผลจำแนก AI ที่ระบบมีอยู่แล้ว ไม่ได้เพิ่มโมเดลใหม่หรือระบบเข้าใจภาษาที่รับรองความถูกต้องทุกประโยค คำปฏิเสธ/ปิดการหาและข้อห้ามยังบล็อกได้แม้ AI ระบุว่าเป็นผู้ซื้อ โพสต์ที่ isAd เป็นจริงยังถูกข้าม รวมถึงกฎคนเสนอขายด้วย

เพิ่ม priority 0–100: สูงกว่าตรวจสอบก่อน หากเสมอใช้ลำดับสร้างกฎ กฎที่เข้าเงื่อนไขและรอ AI ไม่ถูกกฎล่างแย่งไปส่งก่อน หนึ่งโพสต์มี live delivery key เดียวตามเดิม

Worker บันทึก `AutoCommentEvaluation` แยกผลข้าม/รอ AI/รอเวลา/สร้างงาน/มีประวัติเดิม และประเมินใหม่เมื่อ Post, Source หรือ revision ของกฎเปลี่ยน โดยใช้ durable checkpoint แทน cursor อย่างเดียว งานไม่มี checkpoint ถูกตรวจซ่อมได้หลังรีสตาร์ต แต่ละ tick รับสูงสุด 100 โพสต์ ให้โพสต์ยังไม่เคยตรวจมาก่อนแล้วหมุนตรวจ checkpoint เก่า ป้องกันงานรอชุดเดิมยึด batch

ขอบเขตยังเป็นโพสต์รับเข้าหลัง Start ของรอบปัจจุบัน เมื่อแก้กฎ จะตรวจโพสต์ในรอบนี้ใหม่ภายในข้อจำกัดอายุ รวมทั้งโพสต์ที่เคยข้าม แต่ไม่ย้อนก่อน Start งานที่ยกเลิกเพราะข้อมูลเปลี่ยนและพิสูจน์ว่ายังไม่ออก grant อาจเตรียมใหม่ด้วย job/key เดิมใน generation เดียว งานที่เคยเริ่มส่งหรือ uncertain ไม่ถูกเตรียมส่งใหม่

## ติดตั้งรุ่นนี้

รอบพัฒนานี้ยังไม่รัน migration บนฐานจริง และไม่ส่ง Facebook จริง:

1. ให้ทุก Web/Worker ที่ใช้ฐานร่วมกันหยุดก่อนเปลี่ยนรุ่น ทำ backup และตรวจว่ากู้คืนได้
2. ติดตั้ง dependencies และรัน `npm run db:migrate` โดยใช้ DIRECT_URL ของฐานที่ต้องการ รุ่นนี้มี migration `20261112100000_smart_comment_evaluations` เพิ่มสองคอลัมน์กฎและหนึ่งตารางที่เปิด RLS ไม่เปลี่ยน control/consent/quota ของเจ้าของ
3. รัน `npm run build` แล้วเปิด Web และ Worker รุ่นเดียวกัน ตรวจ `/overview` และ readiness ก่อนใช้
4. รุ่นนี้ไม่ได้เปลี่ยนโค้ด Extension ใช้ Extension ที่จับคู่และรองรับ browser comments เดิมได้ ไม่ต้องติดตั้งใหม่เพราะการเปลี่ยนฟอร์มและ evaluator ครั้งนี้

Backup ใหม่รวมตารางผลประเมินด้วย Backup เก่าที่ไม่มีตารางนี้ต้องตรวจด้วย `db:restore -- <file> --check --allow-legacy` ก่อน Restore จริงยังต้องหยุดทุก host และใช้ `--replace`; Restore ปิด automation ตามเดิม อย่าล้างตาราง live jobs เพื่อทดลองซ้ำ

## ตัวอย่างรองเท้า → ลิงก์ Shopee

1. เปิด `/auto-comment` กด **ใช้ตัวอย่าง: คนหารองเท้า**
2. ใส่ข้อความจริง เช่น `แนะนำรองเท้ารุ่นนี้ครับ รายละเอียด: <ลิงก์ Shopee ของคุณ>` ระบบไม่สร้างหรือเดาลิงก์สินค้าให้
3. ตรวจคำสำคัญ `รองเท้า,ร้องเท้า` (คำสะกดผิดเป็น alias ที่เพิ่มชัดเจน ไม่ใช่ fuzzy matching ทุกคำ) และคำยกเว้น
4. เลือกกลุ่มที่อนุญาต อุปกรณ์ บัญชี วันเวลา อายุโพสต์ และโควตา ยืนยันสิทธิ์กลุ่ม หากเปิดรอ AI แต่ไม่มี provider ที่ใช้งานได้ งานจะรอและไม่เปลี่ยนเป็นส่งด้วยกฎแทน
5. บันทึก เปิดกฎ แล้วทดลองข้อความใน Preview: `หารองเท้าวิ่ง`, `ช่วยแนะนำรองเท้าหน่อย`, `ขายรองเท้า`, `ได้รองเท้าแล้ว` Preview ไม่เรียก AI ใช้ข้อความสังเคราะห์กับกฎที่บันทึก จึงเป็นการตรวจ matcher ไม่ใช่การรับรอง AI หรือการส่ง
6. Start ขณะ Dry Run รับโพสต์ใหม่ ตรวจ **ผลประเมินโพสต์รอบปัจจุบัน** และข้อความในประวัติงาน Dry Run ไม่เปิดแท็บส่งหรือกดส่ง
7. การส่งจริงต้องตรวจความพร้อมและได้รับอนุมัติขอบเขตทดสอบจากเจ้าของแยก ปิด Dry Run พร้อมยืนยัน แล้ว Start ใหม่และเปิด local opt-in ใน Extension การเปลี่ยนโหมดไม่ย้ายโพสต์จำลองไปส่งย้อนหลัง

| ข้อความทดสอบ | กฎคนซื้อ + คำรองเท้า |
| --- | --- |
| หารองเท้าวิ่ง งบ 1000 | เข้าเงื่อนไขคำ/เจตนา |
| ช่วยแนะนำรองเท้าหน่อย | เข้าเงื่อนไขคำ/เจตนา |
| ขายรองเท้ามือสอง | ไม่ใช่คนหาซื้อ |
| ได้รองเท้าแล้ว / ไม่หารองเท้าแล้ว | ปิดหรือปฏิเสธ |
| รีวิวรองเท้าที่ใช้อยู่ | ไม่เข้าเงื่อนไขการซื้อจากกฎพื้นฐาน |

ทุกกรณียังต้องผ่านกลุ่ม เวลา อายุ โฆษณา คำต้องห้าม ข้อความ โควตา และตัวตรวจส่งเดิมก่อน ส่งเมื่อพบและเข้าคิว ไม่รับรองว่าจะทันทีที่โพสต์บน Facebook หรือเก็บโพสต์ทุกชิ้นที่ Facebook ไม่แสดงให้ Chrome เห็น เครื่องเจ้าของต้องเปิด Chrome และออนไลน์

## สิ่งที่ยังอยู่ในแผน

Read-only reconciliation สำหรับ uncertain, receipt ราย item/batch, AI Draft ที่ผูก business facts/กฎแยกโดยเฉพาะ, confidence calibration และ fair delivery queue ต่อกลุ่มแบบเต็ม ยังไม่ได้เพิ่มในรอบนี้ AI Draft เดิมยังใช้ suggestedReply ของโพสต์ เจ้าของควรเริ่มด้วยข้อความ Template ที่ตรวจแล้ว ดู [แบบเป้าหมาย](SMART-COMMENT-DESIGN.th.md) สำหรับรายละเอียด ไม่ถือว่าทั้ง roadmap เสร็จแล้ว
