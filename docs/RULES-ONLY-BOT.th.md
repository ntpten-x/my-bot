# บอทตามกฎและผลตรวจระบบคอมเมนต์ — 10 พฤศจิกายน 2026

ระบบรุ่นนี้นำการเรียก AI ออกจากการทำงานแล้ว การรับฟีดและคอมเมนต์ที่ใช้คำสำคัญกับข้อความสำเร็จรูปยังทำงานได้ ไม่ต้องมีโมเดลหรือคีย์ผู้ให้บริการ แต่ยังไม่รับรองว่าทุกโพสต์จะถูกพบและส่งภายในจำนวนวินาทีตายตัว

## สิ่งที่บอทยังทำได้

- Chrome อ่านโพสต์และส่งเข้าระบบตามแหล่งข้อมูลที่เปิดไว้ พร้อมคิวรับข้อมูลและการกู้คืนเดิม
- จัดหมวด เจตนา สินค้า คะแนน และข้อความแนะนำด้วยกฎภาษาไทย คำสำคัญ คำยกเว้น และข้อมูลที่เจ้าของกำหนด
- ค้นด้วยคำจากโพสต์ทั้งหมดตามตัวกรอง เก็บคำแก้ไขของเจ้าของและน้ำหนักจากการบันทึก/ติดต่อลีด
- เลือกข้อความสำเร็จรูป ตรวจอุปกรณ์ บัญชี กลุ่ม วันเวลา โควตา revision และสิทธิ์ Worker ก่อนอนุญาตส่ง
- เก็บ sending journal และประวัติ dedupe เดิม งานที่ผลไม่ชัดเจนไม่ส่งซ้ำอัตโนมัติ

ไม่มีการร่างข้อความใหม่ด้วยโมเดล ค้นด้วย embedding หรืออ่านข้อความในภาพด้วย OCR ข้อความที่มีอยู่เฉพาะในภาพจึงไม่ได้ถูกนำมาจับคู่ การดึงการ์ดโพสต์ รูป และข้อความที่ Chrome อ่านได้ยังอยู่

## สิ่งที่ถอดออก

Worker ไม่เรียกคิวจัดประเภท โมเดล OCR, embedding, การอุ่นโมเดล หรือการจัดใหม่ด้วย AI การรับโพสต์ไม่สร้าง AiJob และตัวจัดประเภทแบบเก่าเรียกได้เฉพาะกฎโดยไม่ใช้ผลโมเดลจากแคช

หน้า Settings ไม่มีแบบฟอร์มผู้ให้บริการหรือคีย์โมเดล หน้า Feed ไม่มีค้นตามความหมาย หน้า Overview, health และ watchdog ไม่ทดสอบหรือบังคับความพร้อม AI ตัวติดตั้งไม่ลงโมเดลหรือเปิด Ollama

API เก่าของผู้ให้บริการ คิว ทดสอบโมเดล และ embedding ตอบ HTTP 410 หลังตรวจการเข้าสู่ระบบ ไม่สามารถเปิดโมเดลกลับผ่านไคลเอนต์รุ่นเก่าได้ กฎใหม่ต้องใช้ข้อความสำเร็จรูป และส่ง requireAi=true หรือ messageMode=ai_draft ไม่ได้

ชื่อคอลัมน์/ตารางเดิม เช่น aiProvider, AiJob และ pending_ai บางส่วนยังอยู่เพื่ออ่าน backup และประวัติรุ่นเก่า รวมถึงฟังก์ชันรองรับไคลเอนต์เก่าที่ไม่เรียกเครือข่าย ไม่ใช่ตัวเลือกเปิด AI กลับ

AI_KEY_SECRET ยังต้องใช้ชื่อเดิมสำหรับเข้ารหัสข้อมูลแจ้งเตือนและ backup ห้ามเปลี่ยนหรือลบทิ้งในการอัปเดตนี้ คีย์โมเดลเก่าถูกละเว้น แม้ถอดรหัสไม่ได้ก็ไม่ขัดขวางการอ่าน Settings

## คะแนนก่อนและหลัง

จึงยังให้ 9++ ทุกส่วนอย่างมีหลักฐานไม่ได้ โดยเฉพาะการทำงานหลายวันและเวลาส่งจริง ไม่มีการเพิ่มโควตาหรือข้ามข้อจำกัดเพื่อทำคะแนนให้สูงขึ้น

ชุดประเมินกฎเริ่มต้นได้ 19/20 หรือ 95% จากข้อความแต่งขึ้น 20 ตัวอย่าง ไม่ใช่ผลกับโพสต์จริง และไม่ได้ใช้เป็นคำรับรองความแม่นยำ 95% ในการใช้งาน

## ตรวจซ้ำ

ใช้ TEST_DATABASE_URL ของฐานทดสอบแยกเท่านั้น เทสต์แต่ละชุดสร้าง schema test_* และลบทิ้ง ไม่ใช้ DATABASE_URL จริงแทน

```powershell
npm.cmd test -- --no-file-parallelism
npm.cmd run build
npm.cmd run evaluate:classifier
git diff --check
```

การรันเรียงไฟล์ช่วยเลี่ยง migration advisory lock ระหว่าง schema ทดสอบ ไม่รันชุดฐานข้อมูลพร้อม Prisma generate/build บน Windows เพราะใช้ DLL เดียวกัน

ผลสุดท้าย: 117 ไฟล์ผ่าน 2 ไฟล์ข้าม รวม 922 ข้อผ่าน 8 ข้อข้ามตามแพลตฟอร์มหรือเครื่องมือที่ไม่มี ไม่มีข้อผิดพลาด ชุดฐานข้อมูลใช้ PostgreSQL ชั่วคราวที่ loopback และ schema test_* จริง Build, TypeScript, diff check และการตรวจ ASCII/ไวยากรณ์ PowerShell ผ่านแล้ว

ตรวจ Settings, Feed, Auto Comment และ Overview ใน Chrome ด้วยเว็บและฐานจำลองแยกแล้ว: ไม่มี page error, API ที่ยกเลิกตอบ 410, คอมเมนต์ยังอยู่ในสถานะหยุด ไม่มี Facebook จริงหรือการส่งคอมเมนต์จริงในการตรวจรอบนี้

## นำไปใช้กับเครื่องจริง

1. สำรองข้อมูลและหยุด MY-BOT web/worker ทุกรุ่นที่ใช้ฐานร่วมกันก่อน migration อย่าให้ Worker รุ่นเก่าที่ยังมี AI ทำงานพร้อมรุ่นใหม่
2. รัน npm install, npm run db:migrate และ npm run build กับฐานที่ตรวจปลายทางถูกต้องแล้ว จากนั้นเปิดเว็บและ Worker รุ่นใหม่
3. อัปเดต/Reload ส่วนขยาย 1.11.26 ตรวจ pairing และบัญชีเดิม ไม่ล้างโปรไฟล์ Chrome
4. ตรวจคำสำคัญและข้อความสำเร็จรูปของกฎเก่า กฎ AI Draft จะถูกปิดไว้ ไม่มีการนำข้อความที่โมเดลเคยสร้างมาเปิดส่งแทนเจ้าของ
5. ถ้าใช้ Startup launcher เก่าที่เปิด Ollama ให้ติดตั้ง launcher รุ่นใหม่ ระบบไม่ได้ถอน Ollama ที่เจ้าของอาจใช้งานอย่างอื่น

รอบนี้ยังไม่ migrate ฐานจริง ไม่ commit/push/deploy และไม่เริ่มส่งคอมเมนต์ ในเครื่องที่ตรวจ doctor ยังพบ DATABASE_URL แบบ SQLite เว็บพอร์ต 8001 ไม่เปิด และไม่มีโทเคนส่วนขยาย จึงยังยืนยันความพร้อมของเครื่องใช้งานจริงไม่ได้

doctor รอบสุดท้ายได้ FAIL 3 / WARN 1 โดยไม่มีการทดสอบหรือแจ้งเตือนเรื่องผู้ให้บริการโมเดล ปิด Chrome, เว็บ และ PostgreSQL ที่สร้างสำหรับทดสอบแล้ว

ก่อนให้คะแนนการทำงานจริง 9++ ต้องมีข้อมูลจากรุ่นใหม่ต่อเนื่อง 24–72 ชั่วโมง วัด ingest→ready→dispatch→observed แบบ p50/p95 แยกเวลาพักโควตา ทดสอบป้ายคำตอบจากโพสต์ที่เจ้าของตรวจแล้ว และมีตัวอย่างส่งจริงที่ได้รับอนุญาตแยกต่างหาก
