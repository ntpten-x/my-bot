# noVNC: การเชื่อมต่อและการปรับภาพ

Desktop 0.1.7-preview ใช้ noVNC UI เดิม เพิ่มเมนู **MY-BOT · การเชื่อมต่อ / ภาพ** ที่มุมล่างขวา รหัสผ่านยังกรอกในหน้าต่างเดิม ไม่ใส่ใน URL หรือ diagnostics

- เชื่อมต่อใหม่หลังหลุดได้สูงสุด 5 ครั้ง เว้น 3/6/12/24/30 วินาที กด Disconnect/Cancel หรือยืนยันตัวตนไม่ผ่านจะหยุด ต้องกด Connect ใหม่ เมื่อเชื่อมต่อสำเร็จจะเริ่มงบ retry ใหม่
- สมดุล = quality 6/compression 2 (ค่าเดิม), เน้นลื่น = 6/0, เน้นคม = 9/0 การลด compression อาจลดงาน CPU แต่เพิ่มข้อมูลส่ง ต้องวัดจริงก่อนเลือก ไม่รับประกันว่าใช้ RAM/CPU น้อยลงทุกเครื่อง
- ความละเอียด Xvfb คง 1600x900x24 ใช้ scale เฉพาะหน้า viewer ไม่ resize เดสก์ท็อป จึงไม่เปลี่ยน viewport ของ Facebook และ reader
- เมนูแสดงจำนวนหลุด ช่วงเชื่อมต่อ (รวมเวลารอกรอกรหัสผ่าน) เวลาเชื่อมต่อล่าสุด และรหัสเหตุผล เฉพาะ viewer รอบนี้ ไม่เก็บรหัสผ่าน ภาพหน้าจอหรือข้อความ Facebook

## เปรียบเทียบก่อนเลือกโหมด

เปิดแท็บ viewer เดียว ใช้หน้าจอและการเลื่อนแบบเดียวกัน เลือกแต่ละโหมดแล้วกด **วัดการตอบสนอง 10 วินาที** ทำซ้ำอย่างน้อยสามครั้ง เปรียบเทียบ p50/p95 ของช่วง requestAnimationFrame (ต่ำกว่ามักตอบสนองดีขึ้น) พร้อม CPU/Memory ของ browser และ x11vnc/websockify จาก Task Manager เครื่องเดียวกัน การวัดนี้ไม่ใช่ FPS ของ Facebook หรือเวลา publish-to-capture และไม่พิสูจน์ว่าภาพสด หยุดวัดทันทีเมื่อซ่อนแท็บ ไม่มี loop วัดถาวร

## ตรวจสุขภาพและกู้คืน

`npm run browser:desktop -- --check` และ `npm run bot:status` ต้องผ่าน HTTP, WebSocket upgrade และ RFB banner จึงถือว่า viewer พร้อม ไม่ใช่เพียง HTTP 200 การ probe ปิดก่อนเลือก authentication ไม่ส่งคำสั่งหรือรหัสผ่าน ไม่ยืนยันว่าล็อกอิน Facebook หรือภาพเคลื่อนไหวได้

supervisor ตรวจเป็นรอบ 15 วินาที ไม่ซ้อน probe เมื่อผิดพลาดสามรอบ จะปิดเฉพาะ Web viewer หรือ Desktop viewer ที่ตนสร้าง ถ้าไม่ยอมปิดภายใน 8 วินาทีจะยุติ child เดิม แล้วใช้ backoff และขอบเขต retry เดิม ก่อนค้างรอตรวจสอบ ไม่เปิด Chrome/Xvfb ใหม่ ไม่แตะ service ที่รับช่วงมา ภาวะ protocol และระยะ probe อยู่ใน components.json ภายใต้ data directory ส่วนตัว ห้ามเผยแพร่ data directory ทั้งชุด

การอัปเดตไฟล์ไม่เปลี่ยน desktop ที่กำลังทำงาน ต้องเริ่ม session/ติดตั้ง Desktop รุ่นใหม่ตามขั้นตอนเดิมจึงได้ public viewer assets ใหม่ อย่ารีสตาร์ตระหว่างมีงานส่งคอมเมนต์ที่ยังไม่ทราบผล รุ่นยังเป็น preview จนกว่าจะตรวจรับ Windows ใหม่และ Facebook แบบอ่านอย่างเดียวจริง
