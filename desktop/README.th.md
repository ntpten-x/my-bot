# MY-BOT Desktop รุ่นทดลอง 0.1.0

สำหรับ Windows 11 x64 ตัวติดตั้งนี้ยังไม่ได้รับรองบน Windows เครื่องใหม่ทุกแบบ ควรทดลองก่อนใช้เก็บโพสต์ต่อเนื่อง ยังไม่ใช่ EXE ที่ลงลายเซ็นแล้ว

1. แตกไฟล์ ZIP ทั้งชุดไว้ด้วยกัน แล้วเปิด **Install.cmd**
2. อ่านคำขออนุญาตก่อนติดตั้ง หากต้องเปิด WSL และรีสตาร์ต Windows ให้กลับมาเปิด Install.cmd อีกครั้งหลังรีสตาร์ต
3. ตั้งรหัสเปิดดูจอบอท 8 ตัวอักษรอังกฤษ ตัวเลข หรือสัญลักษณ์ ไม่ใช้รหัส Facebook ซ้ำ
4. ในจอบอท เข้าสู่ MY-BOT จากเว็บต้นทางของชุดนี้ และเข้าสู่ Facebook ด้วยตนเอง เพื่อเชื่อมอุปกรณ์ใหม่
5. ตรวจภาพรวมระบบว่ามีโพสต์รับจริง แล้วปิดหน้าดูจอได้ โดยอย่าย่อเบราว์เซอร์ภายในจอบอท
6. ใช้ทางลัด **MY-BOT Desktop** ในเมนูเริ่ม เพื่อเปิดดู เริ่ม หยุด ตรวจสถานะ หรือถอนการเริ่มอัตโนมัติ

เครื่องต้องตื่นและต่ออินเทอร์เน็ต การ Sleep/ปิดเครื่องทำให้บอทหยุด การพับฝาโน้ตบุ๊กขึ้นกับการตั้งค่าพลังงานของเครื่อง โปรแกรมไม่เปลี่ยนค่าพลังงานหรือเสียงให้เอง

การติดตั้งครั้งแรกดาวน์โหลดส่วนประกอบเพิ่มเติมและต้องมีพื้นที่ว่างอย่างน้อย 4 GB ไม่ติดตั้งเว็บ ฐานข้อมูล หรือ worker ในเครื่อง ไม่ส่งรหัส Facebook ไป MY-BOT ไม่คัดลอก cookies จาก Chrome ส่วนตัว และไม่เปิดส่งคอมเมนต์ให้เอง

หากดาวน์โหลดหรือ checksum ไม่ผ่าน ให้ดาวน์โหลดใหม่จากเว็บ MY-BOT ที่เชื่อถือได้ อย่าปิดโปรแกรมป้องกันไวรัสเพื่อฝืนติดตั้ง อย่าส่งโฟลเดอร์โปรไฟล์หรือไฟล์ระบบบอทให้ผู้อื่น เพราะอาจมีข้อมูลเข้าสู่ระบบ

อัปเดตโดยพักงาน ตรวจงานส่ง และหยุดบอทก่อน แล้วติดตั้ง ZIP ใหม่จากเว็บเดิม การถอนการเริ่มอัตโนมัติจะเก็บข้อมูลเข้าสู่ระบบและข้อมูลค้างไว้ ไม่ลบสภาพแวดล้อม WSL ทั้งชุดเงียบ ๆ
