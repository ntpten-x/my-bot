# MY-BOT

เรดาร์ลีดส่วนตัวสำหรับคนไทยคนเดียว ใช้บนเครื่อง Windows ของตัวเอง ไม่มีระบบเก็บเงินและไม่มีผู้ใช้คนที่สอง

คุณล็อกอิน Facebook เองใน Chrome แล้วให้ส่วนขยายอ่านโพสต์จากกลุ่มที่คุณเป็นสมาชิกอยู่แล้ว ส่งเข้าแอปบนเครื่องนี้ แอปตัดโพสต์ซ้ำ กรองประกาศขายส่ง จัดหมวด เดาว่าคนกำลังหาหรือกำลังขาย จับจังหวัด แล้วโชว์ในฟีดให้ก๊อปคำตอบไปทักเอง

ส่วนขยาย **อ่านอย่างเดียว** ไม่โพสต์ ไม่คอมเมนต์ และไม่เรียก API ภายในของ Facebook

เอเจนต์ที่เปิดรีโปนี้ให้อ่าน [AGENTS.md](AGENTS.md) ก่อนลงมือ เครื่อง Windows ใหม่ให้เปิดคู่มือ [docs/SETUP.th.md](docs/SETUP.th.md) แล้วรัน

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\setup.ps1
```

ตรวจว่าพร้อมด้วย `npm run doctor` หลังเข้าแอปแล้วดูหน้า **วิธีใช้**

## สิ่งที่ต้องติดตั้งก่อน

1. [Node.js 20 หรือใหม่กว่า](https://nodejs.org) เลือกตัว LTS แล้วกดติดตั้งแบบปกติ
2. Google Chrome
3. ไม่บังคับ แต่แนะนำ: [Ollama](https://ollama.com) ถ้าอยากให้จัดหมวดบนเครื่องตัวเองโดยไม่ใช้คีย์

ตรวจว่า Node พร้อม เปิด PowerShell แล้วพิมพ์

```powershell
node -v
npm -v
```

ต้องขึ้น v20 ขึ้นไป

## ติดตั้งแอป

เปิด PowerShell ในโฟลเดอร์โปรเจกต์นี้

```powershell
Copy-Item .env.example .env
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ที่ [http://localhost:8001](http://localhost:8001)

ครั้งแรกให้ตั้งรหัสผ่านเจ้าของอย่างน้อย 8 ตัว รหัสนี้ใช้เปิดหน้าเว็บบนเครื่องคุณเท่านั้น ระบบจะพาเข้าแดชบอร์ด ซึ่งมีประกาศตัวอย่างให้ดู ลบแหล่งชื่อ “ตัวอย่าง — ลบได้” ได้เมื่อไม่ต้องการ

`npm run dev` เปิดทั้งหน้าเว็บและตัวดึง RSS/เว็บบอร์ด พอร์ตเริ่มต้นคือ 8001 แก้ได้ในไฟล์ `.env` ที่บรรทัด `PORT`

หยุดโปรแกรมด้วย Ctrl+C

## ใส่คีย์ AI ฟรี (ไม่บังคับ)

ระบบลองตามลำดับนี้

1. Ollama บนเครื่อง (ค่าเริ่มต้นโมเดล `qwen2.5:7b`)
2. Google Gemini ถ้ามี `GEMINI_API_KEY`
3. Groq ถ้ามี `GROQ_API_KEY`
4. คำจับคู่ในหมวด ถ้าไม่มี AI หรือตัวก่อนหน้าใช้ไม่ได้

เปลี่ยนลำดับหรือทดสอบการเชื่อมได้ที่หน้า **ตั้งค่า**

### Ollama

1. ติดตั้งจาก https://ollama.com
2. เปิด PowerShell อีกหน้าต่าง

```powershell
ollama pull qwen2.5:7b
```

โมเดลนี้พอใช้กับภาษาไทย ถ้าเครื่องไม่แรงลอง `ollama pull llama3.1:8b` แล้วเปลี่ยนชื่อโมเดลในหน้าตั้งค่า ต้องเปิดแอป Ollama ทิ้งไว้ขณะใช้ MY-BOT

### Gemini

1. เปิด https://aistudio.google.com/apikey
2. สร้าง API key ของแพลนฟรี
3. วางใน `.env` บรรทัด `GEMINI_API_KEY` หรือวางในหน้าตั้งค่า
4. โมเดลเริ่มต้นคือ `gemini-2.0-flash`

### Groq

1. เปิด https://console.groq.com และสมัครแพลนฟรี
2. สร้าง API key
3. วางใน `GROQ_API_KEY`
4. โมเดลเริ่มต้นคือ `openai/gpt-oss-120b` ถ้าบัญชีไม่มีชื่อนี้ ระบบจะเลือกจากรายการโมเดลที่คีย์นี้ใช้ได้ เช่น `openai/gpt-oss-20b` หรือ Qwen

ถ้ายิงถี่เกินโควต้าฟรี ระบบจะข้ามไปตัวถัดไปเอง และจำผลที่จัดได้แล้วไว้ในแคช ล้างแคชได้ในหน้าตั้งค่า

## ติดตั้งส่วนขยาย Chrome

1. เปิด Chrome แล้วเข้า `chrome://extensions`
2. เปิด “โหมดนักพัฒนาซอฟต์แวร์” หรือ Developer mode
3. กด “โหลดส่วนขยายที่คลายแพ็กแล้ว” หรือ Load unpacked
4. เลือกโฟลเดอร์ `extension` ในโปรเจกต์นี้
5. เปิดแอป MY-BOT ที่หน้า **ตั้งค่า** แล้วคัดลอกโทเคนส่วนขยาย
6. กดไอคอน MY-BOT บน Chrome วางที่อยู่ `http://localhost:8001` กับโทเคน แล้วติ๊กเปิดดึงกลุ่มอัตโนมัติ

ถ้าเคยใส่ที่อยู่พอร์ต 3000 ไว้ในส่วนขยาย ให้เปลี่ยนเป็น 8001 แล้วบันทึกใหม่ ปุ่ม **ดึงทันที** ในหน้าแหล่งข้อมูลจะให้ส่วนขยายเปิดกลุ่มนั้นในรอบถัดไป (ประมาณ 30 วินาที) ผลและข้อผิดพลาดอยู่ในการ์ดของแหล่งนั้น และตัวอย่างข้อความที่อ่านได้ดูได้ที่หน้า **ทดสอบตัวอ่าน**

ส่วนขยายจะเปิดกลุ่มที่คุณเพิ่มไว้ในแท็บพื้นหลัง เรียงโพสต์ใหม่สุด อ่านข้อความจากหน้าเว็บ แล้วส่งเข้า `http://localhost:8001/api/v1/ingest` ถ้าคุณเปิดกลุ่มเองขณะล็อกอิน มันก็เก็บโพสต์ของหน้านั้นให้ด้วย

ค่าเริ่มต้นคือทุก 10 นาที บวกสุ่มไม่เกิน 5 นาที (จึงอยู่ช่วง 10–15 นาที) และไม่เกิน 3 กลุ่มต่อรอบ ปรับได้ในหน้าตั้งค่า

Facebook เปลี่ยนหน้าเว็บบ่อย ตัวอ่านโพสต์รวมตัวเลือกไว้ที่ `extension/selectors.js` และมีตัวสำรองเช่น `role=article` กับ aria ถ้ากลุ่มไหนดึงไม่ได้ ให้ดูข้อความผิดพลาดที่หน้าแหล่งข้อมูล

## เพิ่มกลุ่มและแหล่งอื่น

ไปที่หน้า **แหล่งข้อมูล** วางลิงก์กลุ่มแบบนี้ หนึ่งบรรทัดต่อหนึ่งลิงก์

```text
https://www.facebook.com/groups/123456789
https://example.com/feed.xml
```

ลิงก์ที่มี `facebook.com/groups/` จะถูกนับเป็นกลุ่ม Facebook ที่เหลือถ้าดูเหมือน RSS จะให้ตัวหลังบ้านดึง ที่เหลือถือเป็นเว็บบอร์ด

คุณต้องเป็นสมาชิกกลุ่มนั้น และล็อกอิน Facebook ใน Chrome ตัวเดียวกับที่ติดตั้งส่วนขยาย แอปนี้เข้ากลุ่มให้ไม่ได้

## หน้าในแอป

- **แดชบอร์ด** จำนวนลีดวันนี้ ที่ยังไม่อ่าน คนกำลังหา และบันทึกการดึง
- **ฟีดลีด** กรองหมวด หมวดย่อย จังหวัด แหล่ง ช่วงเวลา คำค้น ยังไม่อ่าน หรือที่บันทึก ไฮไลต์คำเฝ้าดู มีอัปเดตสด
- **ไปป์ไลน์** กำลังติดตาม / ทักแล้ว / ปิดการขายได้ / ปิดไม่สำเร็จ พร้อมโน้ต
- **แหล่งข้อมูล** เปิดปิด ดูเวลาที่ดึงล่าสุด จำนวนโพสต์ และข้อผิดพลาด
- **หมวดและคีย์เวิร์ด** แก้หมวดได้ หมวดตั้งต้นมี เกม (เติมเกม, ไอดีเกม, รับจ้างเล่น), ของใช้, อุปกรณ์ไอที, รถ, ฟรีแลนซ์, อสังหา, อื่นๆ
- **การแจ้งเตือน** ในแอป และปุ่มอนุญาตแจ้งเตือนเบราว์เซอร์ ช่อง LINE, Discord, อีเมลตั้งในหน้าตั้งค่า
- **ตั้งค่า** ผู้ให้บริการ AI, ช่วงดึง, โทเคนส่วนขยาย

คำตอบแนะนำให้ก๊อปไปวางเอง แอปไม่ทัก Facebook ให้

แต่ละโพสต์มีคะแนน 0–100 คะแนน 80 ขึ้นไปจะมีป้ายร้อน แจ้งเตือนเฉพาะโพสต์ที่ถึงเกณฑ์ในหน้าตั้งค่า (ค่าเริ่มต้น 50) ช่องค้นหาติ๊ก **ค้นตามความหมาย** ได้ถ้ามีโมเดลฝังข้อความ โพสต์ที่คล้ายกันมากใน 7 วันจะถูกยุบในฟีด

หน้า **เรียนรู้** เสนอคำจากโพสต์ที่คุณบันทึกหรือกดไม่สนใจ หน้า **สรุปรายวัน** ส่งทุกเช้าเวลา 08:00 ตามนาฬิกาไทย เปลี่ยนเวลาได้ในหน้าตั้งค่า

ถ้าจะใช้ค้นตามความหมายบนเครื่อง ให้ดึงโมเดลฝังข้อความด้วย

```powershell
ollama pull bge-m3
```

ถ้าเครื่องไม่ไหว ลอง `ollama pull nomic-embed-text` แล้วเปลี่ยนชื่อในหน้าตั้งค่า ถ้าไม่มี Ollama แต่มีคีย์ Gemini ระบบจะใช้ `text-embedding-004` แทน ถ้าไม่มีทั้งคู่ การค้นความหมายจะถูกข้ามและฟีดยังใช้คำค้นปกติ

## แจ้งเตือนภายนอก

ในหน้าตั้งค่า

- LINE Messaging API: ใส่ channel access token และ user id ของคุณ แล้วกดทดสอบที่หน้าการแจ้งเตือน

## คำสั่งที่ใช้บ่อย

```powershell
npm run dev          # เว็บ + ตัวดึง RSS/เว็บบอร์ด
npm run build        # สร้างชุดพร้อมใช้งาน
npm run start:prod   # รันชุดที่ build แล้ว ที่พอร์ต 8001
npm test             # ทดสอบการตัดซ้ำ ตัวคัดสำรอง และตัวอ่านโพสต์
npm run db:migrate     # อัปเดตฐานข้อมูล
npm run db:seed        # ใส่หมวด คำเฝ้าดู และประกาศตัวอย่าง
npm run db:renormalize # ปรับข้อความไทยและแฮชของโพสต์เดิมหลังอัปเดตตัวตัดคำ
npm run db:backfill-ai # เข้าคิวจัดหมวดโพสต์ที่ยังเป็นกฎ ให้ worker เป็นคนทำ
npm run db:clean-samples # ลบโพสต์ของแหล่งตัวอย่างที่ปิดอยู่
```

ฐานข้อมูลอยู่บน Supabase Postgres ผ่าน Prisma ตั้ง `DATABASE_URL` (Transaction pooler 6543 + `pgbouncer=true`) กับ `DIRECT_URL` (5432) ใน `.env` ทุกตารางเปิด RLS วิธีตั้งค่าและย้ายจาก SQLite เดิม (`npm run db:migrate-from-sqlite`) อยู่ใน `docs/SETUP.th.md`

```bash
npm run db:backup      # ส่งออกทุกตารางเป็น data/backups/manual-*.json.gz
npm run db:restore -- <ไฟล์> --replace  # กู้คืน (หยุดแอปก่อน)
```

## เปิดอัตโนมัติตอนล็อกอิน Windows

ใช้โหมดโปรดักชัน ไม่ใช่ `npm run dev`

```powershell
npm run build
npm run start:prod
```

ให้เริ่มเองทุกครั้งที่ล็อกอิน และรีสตาร์ตถ้าโปรแกรมล่ม

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\install-service.ps1
```

สคริปต์นี้ build ให้หนึ่งครั้ง แล้วพยายามลงทะเบียนงานชื่อ `MY-BOT` ใน Task Scheduler แบบหน้าต่างซ่อน รีสตาร์ตได้ 3 ครั้งห่างกัน 1 นาที ถ้าบัญชีไม่ได้เป็นผู้ดูแลระบบและ Task Scheduler ตอบ access denied สคริปต์จะวาง `MY-BOT.vbs` ในโฟลเดอร์ Startup แทน ไฟล์นั้นเปิด Ollama ที่ `127.0.0.1:41434` แล้วเปิด MY-BOT แบบซ่อนทุกครั้งที่ล็อกอิน

เอาออกทั้งงานและไฟล์ Startup

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\uninstall-service.ps1
```

ทางเลือกด้วย pm2

```powershell
npm install -g pm2
npm run build
pm2 start scripts/start-all.mjs --name my-bot -- --prod
pm2 save
```

บน Windows ถ้าต้องการให้ pm2 กลับมาหลังรีบูต ให้ดูคำสั่ง `pm2-startup` ของเวอร์ชันที่ติดตั้ง

## สำรองฐานข้อมูล

หลัง 03:00 ตามนาฬิกาไทย ถ้าวันนั้นยังไม่สำรอง ตัว worker ส่งออกทุกตารางจาก Supabase ไปที่ `data/backups/ปปปป-ดด-วว.json.gz` และเก็บไว้ 14 วัน หน้าตั้งค่าแสดงไฟล์ล่าสุด

กู้คืน (ข้อมูลในฐานจะถูกแทนที่ทั้งหมดด้วยไฟล์สำรอง)

1. หยุด MY-BOT
2. `npm run db:restore -- data/backups/ปปปป-ดด-วว.json.gz --replace`
3. เปิด MY-BOT อีกครั้ง

สำรองเองเมื่อไรก็ได้ด้วย `npm run db:backup` ได้ไฟล์ `data/backups/manual-....json.gz` นอกจากนี้ Supabase ยังมีสำรองของตัวเองในหน้า Database > Backups

## เมื่อมีปัญหา

- พอร์ต 8001 ถูกใช้อยู่: เปลี่ยน `PORT` ใน `.env` แล้วใส่พอร์ตเดียวกันในป๊อปอัปส่วนขยาย
- หน้าเว็บขึ้นว่าเชื่อมฐานข้อมูลไม่ได้: เช็กเน็ตกับรหัสผ่าน Supabase ใน `.env` แล้วรัน `npm run db:migrate` อีกครั้ง
- ส่วนขยายส่งไม่เข้า: ตรวจว่าแอปยังเปิดอยู่ โทเคนตรงกับหน้าตั้งค่า และที่อยู่เป็น `http://localhost:8001`
- กลุ่มไม่มีโพสต์ใหม่: ต้องล็อกอิน Facebook ใน Chrome นั้น และลิงก์ในหน้าแหล่งข้อมูลต้องเป็นกลุ่มที่คุณเข้าได้
- Ollama ทดสอบไม่ผ่าน: เปิดแอป Ollama ก่อน ถ้าพอร์ต 11434 ใช้ไม่ได้ ให้รัน `set OLLAMA_HOST=127.0.0.1:41434` แล้วเปิด `ollama serve` ระบบจะลอง 11434 ก่อนแล้วจึง 41434
- ค้นตามความหมายไม่เจอ: หน้าตั้งค่ากดทดสอบ embedding แล้วกดเติมโพสต์ที่ยังไม่มีเวกเตอร์ หรือรัน `npm run db:backfill-embeddings` ต้องมีโมเดล `bge-m3` (`ollama pull bge-m3`)
- ลืมรหัสผ่าน: หยุดแอป เปิด Supabase > Table Editor ลบแถวในตาราง `Session` และ `Owner` แล้วเปิด `http://localhost:8001` จะเข้าหน้าตั้งรหัสใหม่ ข้อมูลลีดยังอยู่

## ข้อควรรู้

เก็บแอปนี้ไว้บนเครื่องตัวเอง อย่าเปิดพอร์ตออกอินเทอร์เน็ต เพราะมันมีแค่รหัสผ่านเดียวกับโทเคนของส่วนขยาย

การเปิดแท็บกลุ่มอัตโนมัติอาจทำให้ Facebook จำกัดบัญชีได้ ถ้าใช้หลายกลุ่มให้ถ่างช่วงเวลาและลดจำนวนกลุ่มต่อรอบ

ตัวอ่านโพสต์อยู่ใน `extension/parser.js` ทดสอบกับไฟล์ตัวอย่างใน `extension/fixtures` การตัดซ้ำ การจับคีย์เวิร์ด และตัวคัดสำรองอยู่ใน `tests/pipeline`

## Auto Comment (เปิดใช้เอง)

หน้า `/auto-comment` เพิ่มกฎ/ข้อความ/Allowlist พร้อม Dry Run, Queue, Emergency Stop และ Audit Log ค่าเริ่มต้นปิด ส่งจริงผ่าน API ทางการเฉพาะโพสต์ของเพจที่มีสิทธิ์; กลุ่ม/Marketplace เตรียมข้อความให้ส่งเอง Extension ยังคงอ่านอย่างเดียว ดู [คู่มือและข้อจำกัด](docs/AUTO-COMMENT.th.md) ก่อนตั้ง Credential หรือ Apply Migration
